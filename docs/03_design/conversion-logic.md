# 変換ロジック設計

## 概要

柱状図データと圧入管理データのペアから、地層ごとの圧入自動運転設定値を導出する変換ロジックの設計仕様。

全体構成は [system-architecture.md](system-architecture.md) を参照。

## 前提条件

- 入力は .pilx + XML のデータペア
- 1ペアにつき1杭の施工実績と1本のボーリング柱状図
- 柱状図の地層区間で圧入データを分割し、地層ごとの特徴量を抽出する
- 蓄積されたデータから土質分類×N値範囲ごとの推奨設定値を集約する

## 変換の流れ

### Step 1: 地層への圧入データ割り当て

柱状図の各地層区間に対して、圧入管理データの深度列を参照し、該当する時系列行を抽出する。

```
地層 [砂質土, 0-3000mm]
  → 圧入データの depth が 0〜3000mm の行を抽出
  → フィルタ: チャック下=1（圧入動作中のみ）
```

### Step 2: 特徴量抽出

各地層区間の圧入データから以下を算出：

- **実績値**: 圧入力(mean/max)、圧入速度(mean/max)、オーガトルク、水量
- **設定値**: オペレータが設定した各パラメータの最頻値

### Step 3: テーブル蓄積

地層×特徴量の組を個別レコードとして蓄積する（レベル1テーブル）。

### Step 4: 集約

土質大分類×N値レンジで集約し、推奨設定値テーブル（レベル2テーブル）を生成する。

## 変換ルール

### 土質大分類の決定

柱状図の土質記号から大分類を判定する：

| 土質記号（例） | 大分類 |
|---|---|
| C, Cl, CL, CH | 粘性土 |
| M, ML, MH, SM | シルト・シルト質土 |
| S, SF, SW, SP | 砂質土 |
| G, GF, GW, GP | 礫質土 |
| WR, MR, HR | 岩盤 |
| FI | 埋土（土質記号から再分類） |

> 詳細な分類ルールは `docs/02_analysis/geology-classification.md` で定義する

### N値の代表値

地層内に複数のN値測定点がある場合、平均値を代表値とする。

- N値 = 99999（打撃拒否）→ 便宜上 N=60 として扱う（要検討）
- N値 = 0（自沈）→ そのままN=0
- 地層内にN値測定点がない場合 → 上下の層のN値から線形補間（要検討）

### 設定値の推奨値算出

| 指標 | 算出方法 | 根拠 |
|---|---|---|
| 推奨圧入力設定 | setting_press_force の最頻値 | 熟練オペレータの判断を反映 |
| 参考圧入力 | press_force_mean の中央値 | 実績の傾向把握 |
| 推奨速度設定 | setting_speed の最頻値 | 同上 |
| 信頼度 | サンプル数に基づく | n≥10:高、3≤n<10:中、n<3:低 |
