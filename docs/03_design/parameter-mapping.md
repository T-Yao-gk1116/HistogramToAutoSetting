# パラメータマッピング定義

## 概要

地質パラメータ（入力）と圧入自動運転設定値（出力）のマッピングルールを定義する。

全体構成は [system-architecture.md](system-architecture.md) を参照。

## 入力パラメータ（地質情報）

| パラメータ | ソース | 説明 |
|---|---|---|
| 土質大分類 | 柱状図 XML / PILX フッター | 粘性土/砂質土/礫質土/岩盤 |
| 土質名 | 柱状図 XML / PILX フッター | 細分類名称 |
| N値（平均） | 柱状図 XML（標準貫入試験） / PILX フッター | 地層内のN値平均 |
| N値（最大） | 同上 | 地層内のN値最大 |
| 層厚 | 柱状図 XML | 地層の厚さ |
| 深度 | 柱状図 XML | 地層の上端・下端深度 |
| 地下水位 | 柱状図 XML（孔内水位）/ PILX INI56 | 地下水面の深度 |

## マッピングテーブル（テンプレート）

データ蓄積により以下のテーブルが生成・更新される。36パラメータすべてを列として持つ。

### テーブルキー

```
(土質大分類, N値ビン) → 36個の設定値
```

### 各セルの値

| 値の種類 | 算出方法 | 説明 |
|---|---|---|
| 推奨値 | 同一キーの全レコードの最頻値 | 熟練オペレータの判断を反映 |
| 参考値（平均） | 同一キーの全レコードの中央値 | 実績の傾向把握 |
| 参考値（範囲） | min〜max | 値のばらつき把握 |

## マッピングの粒度

### 将来的な拡張キー

サンプル数が十分に蓄積されたら、以下の軸を追加する：

- 杭仕様（矢板種別×長さ）
- 工法（単独/ジェット併用/オーガ併用）
- 地下水位との関係（水位上/水位下）

### パラメータの有効性

工法によって使用するパラメータが異なる：

| 工法 | 使用するカテゴリ | 未使用カテゴリ |
|---|---|---|
| 矢板単独 | A, B, C, D, E | F, G, H, I |
| 矢板ジェット併用 | A, B, C, D, E, F, I | G, H |
| 矢板オーガ併用 | A, B, C, D, E, F, G, I | H |
| コンビジャイロ | A, B, C, D, E, F, G, H, I | — |

> 未使用カテゴリのパラメータはテーブル上 null として扱う。
