# 圧入管理データ仕様

## 概要

圧入機の運転中に記録される管理データの仕様を定義する。フォーマットは **PILX 形式** と **バイナリ形式** の 2 種類がある。

## フォーマット種別

| フォーマット | 拡張子 | 特徴 | 詳細 |
|---|---|---|---|
| PILX 形式 | `.pilx` | テキスト（CSV 類似）のセクション構造 | [→ 1. PILX 形式](#1-pilx-形式) |
| バイナリ形式 | — | 固定長バイナリ、ヘッダー部・データ部・フッター部で構成 | [→ 2. バイナリ形式](#2-バイナリ形式) |

---

# 1. PILX 形式

## データソース

| 項目 | 内容 |
|---|---|
| データ提供元 | 圧入機の管理システム |
| フォーマット | .pilx（テキスト/CSV 類似のセクション構造） |
| 更新頻度 | 1杭の施工完了ごとに1ファイル生成 |
| サンプル | `data/samples/No8_20240612134904_No.8.pilx` |

## ファイル全体構造

```
[ヘッダーセクション]    ← 現場情報・機械情報・設定
[データセクション]      ← 100ms間隔のセンサデータ（CSV）
[フッターセクション]    ← 柱状図データ（地層・N値・水位）
```

## 品質要件

- 欠損許容率：経過時間・深度は欠損不可
- 値域チェック：深度 ≥ 0、経過時間は単調非減少
- 整合性チェック：最終列の Unix タイムスタンプと INI24/INI25 の整合
- N値の特殊値：99999 は拒否（測定不能）として扱う

## 備考

- 圧入機の機種・システムバージョンによりカラム数・INI パラメータが異なる可能性がある
- 設定値カラムの単位は未確認（機械のマニュアル等で要確認）
- 運転モード・工法フラグの値の定義は要確認
- 深度（データ部）の単位は mm、柱状図部の深度単位は cm で異なるため注意

# 2. バイナリ形式

## 概要

圧入機の管理システムが出力する固定長バイナリ形式のデータ。PILX 形式と同等の情報を格納するが、コンパクトなバイナリ表現を用いる。

## ファイル全体構造

```
[ヘッダー部]   ← 機械情報・動作フラグ・エラーコード
[データ部]     ← 計測値・設定値（16ビット整数）
[フッター部]   ← GPS 座標データ
```

---

## 1. ヘッダー部

機械識別情報・動作フラグ・エラー状態をバイト列で格納する。

### 1.1 バイラー特性値
