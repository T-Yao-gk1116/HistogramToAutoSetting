# 柱状図データ仕様（ボーリング交換用データ XML）

## 概要

国土交通省の「地質・土質調査成果電子納品要領」に基づくボーリング交換用データ（XML形式）の仕様を定義する。DTD_version により XML構造が異なるため、全バージョンに対応する設計が必要。

## データソース

| 項目 | 内容 |
|---|---|
| データ提供元 | ボーリング調査報告書（電子納品成果） |
| フォーマット | XML（Shift_JIS エンコーディング） |
| ファイル命名規則 | `BED?????.XML`（?は連番） |
| DTD ファイル | `BED????.DTD`（バージョンに対応） |
| サンプル | `data/samples/BED0001.XML`（DTD_version 5.00） |

## DTD バージョン履歴

| バージョン | DTDファイル | 時期 | 主な変更点 |
|---|---|---|---|
| 1.02 | BED0100.DTD | 2001/05 | 一軸試験破壊ひずみの分割 |
| 1.10 | BED0110.DTD | 2001/05 | DTDエンコーディングをUnicodeに変更、N値記録用具追加 |
| 2.00 | BED0200.DTD | 2002/02 | 全面改訂（岩盤・地すべり柱状図様式追加） |
| 2.01 | BED0201.DTD | 2003/03 | 多数の項目を必須→任意に変更 |
| 2.10 | BED0210.DTD | 2004/04 | 標準貫入試験詳細データ追加、ルジオン試験改訂 |
| 3.00 | BED0300.DTD | 2008/03 | 基礎情報_適用規格追加、土質岩種区分→岩石土区分に名称変更 |
| 4.00 | BED0400.DTD | 2016/05 | 公開フラグ追加、多数の項目名変更、貫入量cm→mm |
| 5.00 | BED0500.DTD | 2026/03 | 試錐機・エンジン・ポンプを任意化、色調名・孔内水位を任意化 |

## XML 全体構造

```xml
<?xml version="1.0" encoding="Shift_JIS"?>
<!DOCTYPE ボーリング情報 SYSTEM "BED0500.DTD">
<ボーリング情報 DTD_version="5.00">
  <基礎情報>...</基礎情報>          <!-- v3.00〜 -->
  <標題情報>...</標題情報>
  <コア情報>...</コア情報>
</ボーリング情報>
```

## 圧入設定値生成に必要な項目（★重要）

本プロジェクトの目的である「柱状図→圧入設定値」の変換に必要な情報を以下にまとめる。

### 1. ボーリング基本情報

| 要素 | 説明 | 単位 | 型 |
|---|---|---|---|
| 孔口標高 | ボーリング孔口の標高 | m | float |
| 総削孔長 | ボーリングの総掘進長 | m | float |

### 2. 地層情報（工学的地質区分名現場土質名）

各地層を下端深度で区切り、土質を定義する。

| 要素 | 説明 | 単位 | 型 |
|---|---|---|---|
| `_下端深度` | 地層の下端深度 | m | float |
| `_工学的地質区分名現場土質名` | 土質名（例：シルト質砂、礫、軟岩） | — | string |
| `_工学的地質区分名現場土質名記号` | 記号（例：SM, G, WR） | — | string |
| `_岩石群コード` | 岩石の構成数（1=単一、2+=互層等） | — | int |
| `_岩石` | 岩石コード（9桁） | — | string |

サンプルの地層構成：

| # | 深度範囲 (m) | 層厚 (m) | 土質名 | 記号 |
|---|---|---|---|---|
| 1 | 0.00 - 1.80 | 1.80 | 埋土（砂） | FI |
| 2 | 1.80 - 3.00 | 1.20 | シルト質砂 | SM |
| 3 | 3.00 - 7.40 | 4.40 | シルト混じり砂 | S-M |
| 4 | 7.40 - 10.60 | 3.20 | シルト質砂 | SM |
| 5 | 10.60 - 22.45 | 11.85 | シルト | M |
| 6 | 22.45 - 23.70 | 1.25 | 粘性土 | C |
| 7 | 23.70 - 24.55 | 0.85 | シルト混じり砂 | S-M |
| 8 | 24.55 - 27.95 | 3.40 | 砂・シルト互層 | S・M |
| 9 | 27.95 - 30.15 | 2.20 | 礫 | G |
| 10 | 30.15 - 32.15 | 2.00 | 軟岩 | WR |

### 3. 標準貫入試験（N値）

| 要素 | 説明 | 単位 | 型 |
|---|---|---|---|
| `_開始深度` | 試験開始深度 | m | float |
| `_0_100打撃回数` | 0〜100mm貫入における打撃回数 | 回 | int |
| `_0_100貫入量` | 0〜100mm区間の貫入量 | mm（v4.00〜）/ cm（v3.00以前） | int |
| `_100_200打撃回数` | 100〜200mm区間の打撃回数 | 回 | int |
| `_100_200貫入量` | — | mm / cm | int |
| `_200_300打撃回数` | 200〜300mm区間の打撃回数 | 回 | int |
| `_200_300貫入量` | — | mm / cm | int |
| `_合計打撃回数` | **N値に相当**（300mm貫入した場合） | 回 | int |
| `_合計貫入量` | 合計貫入量 | mm / cm | int |
| `_備考` | 「ハンマー自沈」等の特記事項 | — | string |

> **N値の算出ルール：** `合計貫入量 ≥ 300mm` の場合、N値 = `合計打撃回数`。`合計貫入量 < 300mm` の場合は打撃拒否で N値 ≥ 50。`打撃回数 = 0` で「ハンマー自沈」の場合は N値 = 0。

### 4. 孔内水位

| 要素 | 説明 | 単位 | 型 |
|---|---|---|---|
| `_測定年月日` | 測定日 | — | date |
| `_孔内水位` | 地下水位深度 | m | float |

### 5. 地盤材料の工学的分類

| 要素 | 説明 | 型 |
|---|---|---|
| `_下端深度` | 分類の下端深度 | float |
| `_工学的分類記号` | JIS分類記号（ML, SF, CL等） | string |

## パーサ設計方針（全バージョン対応）

### 1. バージョン判定

```
DTD_version = ルート要素 "ボーリング情報" の DTD_version 属性
```

### 2. 要素名のマッピング戦略

DTD_version に基づいて要素名のエイリアスマッピングを行い、内部的には統一した名前で扱う。

```python
# 例：地層情報の要素名マッピング
SOIL_TYPE_ELEMENT = {
    "1.02": "土質岩種区分",
    "1.10": "土質岩種区分",
    "2.00": "土質岩種区分",
    "2.01": "土質岩種区分",
    "2.10": "土質岩種区分",
    "3.00": "岩石土区分",
    "4.00": "工学的地質区分名現場土質名",
    "5.00": "工学的地質区分名現場土質名",
}
```

### 3. 貫入量の単位正規化

v3.00以前の cm を mm に変換して統一する。

### 4. 任意要素の安全な取得

存在しない可能性のある要素はデフォルト値を設定する。

### 5. エンコーディング

XML宣言の `encoding="Shift_JIS"` を尊重する。Python では `open(file, encoding='shift_jis')` で読み込む。

## 品質要件

- DTD_version の存在確認：ルート属性が必須
- 地層情報の連続性：上層の下端深度 = 下層の上端深度（上端深度は前層の下端深度から暗黙的に決定）
- N値の整合性：合計打撃回数・合計貫入量が区間データの合計と一致
- 深度の単調増加：地層・N値の深度は単調増加であること

## 備考

- v2.00 未満のデータは現存が少ないため、v2.00 以降を優先対応する
- `.pilx` ファイルのフッターに埋め込まれた柱状図データは簡易形式であり、本仕様のXML形式とは構造が異なる。両形式からの統一的な地質情報抽出が必要
